## 3. 已知问题

### 3.1 后端测试失败

- **命令**: `cd backend && python -m pytest --collect-only -q`
- **退出码**: 1
- **错误**: `No module named pytest`
- **影响**: 无法运行后端测试
- **修复**: WP1 需要创建虚拟环境并安装 pytest

### 3.2 MCP Cargo 编译失败

- **命令**: `cd esragpro-mcp && cargo check`
- **退出码**: 101
- **错误**: `ort = "^2"` 版本选择失败
- **详情**: crates.io 只有 2.0.0-rc.* 候选版本，没有稳定版
- **影响**: MCP Gateway 无法编译
- **修复**: WP0 需要创建 SDK spike，确定正确的依赖版本

### 3.3 业务代码缺陷

根据 PLAN.md 1.1 节和代码审查：

1. **kb.upload**: 调用不存在的 `index_document_with_graph` (backend/app/api/kb.py)
2. **graph_rag**: 传 `query_vector=None` 给 kNN (backend/app/services/graph_rag.py)
3. **raw search**: 未导入 `rag_service` (backend/app/api/kb.py)
4. **公开注册**: 允许客户端提交 `role` (backend/app/api/auth.py)
5. **图查询**: 固定返回空列表 (backend/app/services/graph_rag.py)

这些缺陷将在 WP1 中修复。
