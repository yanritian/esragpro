## 快速导航

### 我是开发者/运维

1. 先看 [INSTALL.md](deployment/INSTALL.md) 了解如何部署
2. 再看 [architecture.md](deployment/architecture.md) 理解系统架构
3. 部署时参考 [security-guide.md](deployment/security-guide.md)

### 我是销售人员

1. 先看 [product-ppt.md](sales/product-ppt.md) 了解产品
2. 再看 [sales-law-firms.md](sales/sales-law-firms.md) 学习话术
3. 报价时用 [pricing.md](sales/pricing.md) 和 [quotation-template.md](sales/quotation-template.md)

### 我是产品经理/决策者

1. 先看 [technical-roadmap.md](planning/technical-roadmap.md) 了解技术规划
2. 再看 [user-personas.md](planning/user-personas.md) 确定目标客户
3. 风险评估看 [risks-and-challenges.md](planning/risks-and-challenges.md)
