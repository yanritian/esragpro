## 1. 验证目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **Recall@10** | ≥ 95% | 正确答案在 Top 10 召回中的比例 |
| **NDCG@10** | ≥ 0.85 | 排序质量 |
| **端到端准确率** | ≥ 90% | LLM 最终回答的正确率 |
| **幻觉率** | ≤ 5% | 回答中包含文档未提及信息的比例 |

## 3. 评测指标详解

### 3.1 Recall@K

```
定义：正确答案在 Top-K 召回结果中的比例

公式：Recall@K = (正确答案在 Top-K 中的问题数) / (总问题数)

示例：
• 问题总数：100
• 正确答案在 Top-10 中的问题数：95
• Recall@10 = 95/100 = 95%
```

### 3.2 MRR (Mean Reciprocal Rank)

```
定义：正确答案排名倒数的平均值

公式：MRR = (1/N) × Σ(1 / rank_i)

示例：
• 问题1：正确答案排名第2 → 1/2 = 0.5
• 问题2：正确答案排名第1 → 1/1 = 1.0
• MRR = (0.5 + 1.0) / 2 = 0.75
```

### 3.3 NDCG@K (Normalized Discounted Cumulative Gain)

```
定义：考虑排序位置的归一化增益

公式：NDCG@K = DCG@K / IDCG@K

其中：DCG@K = Σ(rel_i / log2(i+1))

用途：评估排序质量，越靠前权重越高
```

### 3.4 端到端准确率

```
定义：LLM 最终回答的正确率

评估方式：
• 人工评判：专家对答案打分
• LLM 评判：GPT-4 对答案评分
• 参考比对：与标准答案相似度

评分标准：
• 正确：答案准确、完整
• 部分正确：答案部分准确或有遗漏
• 错误：答案错误或答非所问
• 幻觉：答案包含文档未提及的信息
```

### 5.2 评测脚本框架

```python
# 评测流程伪代码
def evaluate_rag(dataset, search_fn, llm_fn):
    results = []

    for qa in dataset:
        # Step 1: 检索
        retrieved_docs = search_fn(qa.question, k=10)

        # Step 2: 计算 Recall@K
        recall = calculate_recall(retrieved_docs, qa.ground_truth)

        # Step 3: 生成答案
        answer = llm_fn(qa.question, retrieved_docs)

        # Step 4: 评估答案质量
        accuracy = evaluate_answer(answer, qa.answer, qa.source_doc)

        results.append({
            'question': qa.question,
            'recall': recall,
            'accuracy': accuracy,
            'answer': answer
        })

    return aggregate_metrics(results)
```
