# 律所销售话术与产品演示方案

## 一、律所客户画像

### 决策者

| 角色 | 关注点 | 痛点 |
|------|--------|------|
| 管理合伙人 | 效率、成本、风险 | 案件查找慢、知识流失 |
| 执行合伙人 | 实用性、易用性 | 培训成本高、新人上手慢 |
| IT负责人 | 安全、部署 | 数据不能外泄、系统要稳定 |

### 典型场景

```
场景1：新人培训
"新来的律师，以前办过的类似案例在哪？以前怎么判的？"

场景2：案件研究
"这个案子的法律依据是什么？有没有类似的判例？"

场景3：文书撰写
"这种合同的模板在哪？以前是怎么写的？"

场景4：知识传承
"老合伙人退休了，他的经验怎么留下来？"
```

## 二、开场话术

### 2.1 电话/微信开场

```
话术 A（直击痛点）：
"XX律师，我了解到很多律所都在用 AI，但最大的担心是 AI 会编造内容。
我们做了一个专门解决这个问题的产品，能让 AI 的每个回答都标注来源，
如果文档里没有相关信息，AI 会直接说'不知道'而不是编造。"
```

```
话术 B（场景切入）：
"XX律师，您所里的律师找以前的案例，一般要花多长时间？
我们的产品能让这个时间从几小时缩短到几秒钟，而且每个结果都有来源依据。"
```

```
话术 C（同行背书）：
"XX律师事务所已经在用了，他们反馈以前律师查案例要2小时，
现在10秒就能找到，而且每个回答都注明了出自哪份文件。"
```

### 2.2 约见面/演示

```
"能不能约个20分钟，我给您演示一下？您可以现场试几个真实的法律问题，
看看 AI 是怎么回答的，是不是真的能找到依据。"
```

## 三、演示方案

### 3.1 演示准备清单

```
准备材料：
├── 演示账号（已上传律所常用文档）
│   ├── 民法典相关条款
│   ├── 典型案例判决书
│   ├── 合同模板
│   └── 所内管理制度
│
├── 测试问题清单（提前准备好）
│   ├── 简单问题：能直接找到的
│   ├── 复杂问题：需要推理的
│   └── 超纲问题：文档里没有的
│
└── 对比材料
    ├── 其他产品会编造的回答
    └── 我们产品会拒绝的回答
```

### 3.2 演示流程（20分钟）

#### 第一步：问题引入（2分钟）

```
话术：
"XX律师，在演示之前，我想先了解一下您平时遇到的一些情况：

1. 您所里的律师查以前的案例，一般要花多长时间？
2. 新来的律师上手，需要培训多久？
3. 您有没有遇到过 AI 给出错误信息的情况？"

（记录客户回答，后面针对性解决）
```

#### 第二步：产品介绍（3分钟）

```
话术：
"我简单介绍一下我们的产品 esRAGPro。

核心就是一句话：让 AI 的每个回答都有据可查，不会编造。

有三个特点：
1. 混合检索：同时用关键词和语义搜索，找得更准
2. 幻觉防护：如果文档里没有，AI 会直接说"不知道"
3. 来源追溯：每个回答都标注出自哪个文档"

（打开产品界面）
```

#### 第三步：场景演示（10分钟）

**场景1：案例检索**

```
操作：
1. 在搜索框输入："租赁合同纠纷，租客违约，房东如何维权？"
2. 展示搜索结果

话术：
"您看，系统找到了相关的案例和法条。
重点是这里（指着来源标注），每个回答都标注了 [来源：民法典第xxx条]。

您可以点开这个来源，直接跳到原文验证。"
```

**场景2：复杂问题**

```
操作：
输入一个需要综合多个文档的问题

话术：
"这个问题涉及多个方面，系统会把相关的内容都找出来，
并且标注每个观点的出处。"

（展示置信度）
"您看这个置信度评分，0.85，说明非常可靠。
如果置信度低，系统会自动提醒您'建议人工核实'。"
```

**场景3：超纲问题（关键亮点）**

```
操作：
输入一个文档里没有的问题，比如：
"贵所去年的营收是多少？"（假设文档里没有）

话术：
"现在我问一个文档里没有的问题。"

（展示 AI 回复：抱歉，根据现有知识库文档，我没有找到相关信息）

"您看，AI 不会编造，而是直接告诉您'没有找到'。
这是其他产品做不到的，它们可能会瞎编一个答案。

在法律行业，这一点太重要了——宁可不知道，也不能瞎说。"
```

#### 第四步：安全介绍（3分钟）

```
话术：
"对于律所来说，数据安全也很重要。

我们的产品：
1. 完全私有部署，数据存在您自己的服务器上
2. 所有端口隔离，外部无法访问
3. 支持 HTTPS 加密

简单说：您的案件数据，一分一毫都不会离开您的服务器。"
```

#### 第五步：收尾（2分钟）

```
话术：
"XX律师，您觉得这个产品对您所里有没有帮助？
有没有什么问题想详细了解的？"

常见问题应对：
Q: "价格多少？"
A: "根据律所规模不同，我可以给您一个详细的报价方案，
   我们也支持先试用再购买。"

Q: "部署需要多久？"
A: "如果用云服务器，我们一周内就能部署好。
   您只需要提供要上传的文档，其他的我们来处理。"

Q: "我们已经有知识库了。"
A: "您现在用的什么系统？我们的产品可以直接导入现有数据，
   而且我们的幻觉防护是独一无二的。"
```

## 四、异议处理

### 4.1 "太贵了"

```
回应：
"我理解您的顾虑。我们来算一笔账：

一个律师查资料，一天花2小时，一小时500块，
一天就是1000块，一个月就是2万块。

如果我们的产品能节省50%的时间，一个月就省1万块。
一个律师一年省12万，10个律师就是120万。

我们的产品一年才几万块，投入产出比是很高的。"
```

### 4.2 "我们已经有类似系统了"

```
回应：
"您现在用的是什么系统？效果怎么样？

我建议您可以做个对比测试：
用同样的问题，分别问两个系统，
看看哪个找得更准，哪个更不容易编造。

我们对自己的产品很有信心，欢迎您实测。"
```

### 4.3 "律师们不一定会用"

```
回应：
"我们的系统非常简单，就像用搜索引擎一样。
律师只需要输入问题，剩下的系统自动完成。

而且我们提供完整的培训，现场教律师怎么用，
通常10分钟就能学会。

如果律师们有反馈，我们也会持续优化产品。"
```

### 4.4 "需要跟合伙人讨论"

```
回应：
"没问题，这个决定确实需要团队一起讨论。

我可以给您发一份详细的资料，包括：
1. 产品介绍PPT
2. 客户案例
3. 报价方案

您方便的时候，我可以再跟您的合伙人一起开个会，
详细演示和解答问题。"
```
