## 第一部分：行业痛点

### 企业知识管理的困境

**信息分散，查找困难**
- 文档存放在不同系统，难以统一检索
- 找一份资料平均耗时 30 分钟以上
- 新员工上手慢，培训成本高

**知识流失严重**
- 员工离职，经验随之流失

| 担忧 | 比例 |
|------|------|
| 担心 AI 编造信息 | 78% |
| 不知道答案来源 | 65% |
| 数据安全顾虑 | 52% |
| 无法追溯验证 | 45% |

> 律师追问："依据是什么？"

## 第三部分：核心技术

### 混合检索技术

```
传统方案（仅向量检索）：
问："怎么请假" → 找不到（文档写的是"休假申请"）

我们的方案（混合检索）：
问："怎么请假"
  ├── BM25：找包含"请假"关键词的文档
  ├── 向量：找语义相似的文档
  └── RRF 融合：合并结果，综合排序

结果：两份相关文档都能找到
```

### RRF 融合算法

```
RRF_score = 1/(k + rank_BM25) + 1/(k + rank_向量)

优势：不需要调权重，自动平衡两种检索
```

### 三层幻觉防护系统

```
用户提问
    │
    ▼
┌─────────────────────────────────┐
│ 第一层：安全提示词              │
│ • 必须基于文档回答              │
│ • 每个观点标注来源              │
│ • 禁止模糊词汇                  │
└──────────────┬──────────────────┘
               ▼
┌─────────────────────────────────┐
│ 第二层：事实核查                │
│ • 验证每个声明有来源支撑        │
│ • 移除无法验证的内容            │
│ • 计算置信度评分                │
└──────────────┬──────────────────┘
               ▼
┌─────────────────────────────────┐
│ 第三层：拒绝机制                │
│ • 无信息 → 拒绝回答             │
│ • 信息不足 → 添加警告           │
└──────────────┬──────────────────┘
               ▼
         可信的回答
```
