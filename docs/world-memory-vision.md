# 动态世界记忆愿景

> 文档日期：2026-07-23
> 状态：长期战略方向，当前处于 Phase 2-A 参考存储阶段

## 一句话定位

esRAGPro 正在演进为 **Evidence-grounded Agent Memory Plane**：一个为 Agent 提供证据约束记忆的通用基础设施，保存实时状态、历史事实、关系图谱和证据上下文，让 Agent 在回答和行动时有据可依、无据则拒。

## 产品形态

esRAGPro 的长期产品形态是 **Evidence-grounded Agent Memory Plane**，不是：

- 世界模型（World Model）：不负责预测物理演化
- 规划器（Planner）：不负责制定任务计划或搜索策略
- 实时控制器（Controller）：不负责发送控制指令或驱动执行器
- 物理安全层：碰撞避免、紧急停机等物理安全职责由场景特定的 Safety Controller 独立承担；**Memory Plane 不承担碰撞避免和物理安全等职责**（职责在 Safety Controller，不在 Memory Plane）

Memory Plane 只做它最擅长的事：**记录、组织、检索和提供可审计的证据上下文**。

## 平面职责边界

| 平面 | 职责 | 不做什么 |
|---|---|---|
| **Memory Plane** | 保存观察、状态、假设、事实、冲突、历史和证据 | 不做预测、不做规划、不做动作 |
| **Agent Plane** | 推理、计划、调度、人工审批、任务执行 | 不直接管理持久化存储 |
| **World Model** | 预测下一步状态或物理演化 | 不管理长期记忆 |
| **Control Plane** | 开发调度、任务分配、租约管理、验收 | 不参与运行时产品逻辑 |

## 场景阶梯

esRAGPro 的记忆能力可以服务从简单到复杂的多个场景层级：

### 第一层：通用 Agent 记忆

任何需要跨会话记忆的 AI Agent：对话历史、用户偏好、工具调用结果、事实积累。

### 第二层：企业决策记忆

企业知识库、文档检索、合规审计、决策追溯。当前 esRAGPro 的核心场景。

### 第三层：Coding Agent 项目记忆

**第一商业验证场景。** 代码库结构、API 合同、历史决策、bug 修复模式、代码审查意见。让 Coding Agent 在多次会话中保持项目理解，不重复犯错。

### 第四层：IT/SRE/SOC 事故记忆

**第二商业验证场景。** 事件时间线、根因分析、修复步骤、影响范围、关联告警。让 SRE/SOC 团队在事故响应时快速检索历史经验，缩短 MTTR。

### 第五层：工业作业记忆

制造执行、质量检测、设备维护、工艺参数。需要与 SCADA/MES 集成，支持时序数据和设备状态。

### 第六层：无人机救援记忆

**长期架构压力测试和示范场景。** 搜索区域状态、无人机位置、传感器数据、历史救援记录、风险事实。用于验证记忆系统在高频、高并发、强实时场景下的极限能力。

### 第七层：具身智能记忆

机器人操作、环境感知、任务执行历史。需要融合视觉、力觉、位置等多模态传感器数据。

### 第八层：自动驾驶记忆

驾驶场景、交通状态、决策历史、边缘案例。需要满足车规级安全和法规要求。

## 对外口径调整

### 从"绝对零幻觉"到"证据约束和无证据拒答"

- ❌ **不再宣称**："0 幻觉"、"绝对准确"、"永不编造"
- ✅ **改为宣称**："证据约束"、"无证据则拒答"、"每个回答可追溯到来源"

理由：

1. "0 幻觉"是对 LLM 输出的数学保证，当前技术无法实现
2. "证据约束"是可实现工程目标：通过检索、验证和拒答机制，把无证据内容控制在可接受范围
3. "可追溯"是可验证承诺：每个回答都标注来源，用户可自行核实

## Frontend 决策

**Frontend 冻结，不删除。**

- Vue 3 Frontend 仍保留，作为旧管理面
- 当前不是记忆核心依赖
- 可在 API/TUI/MCP 运维能力成熟后从默认产品中移除
- 不在当前阶段删除或重写

## 商业验证优先级

| 优先级 | 场景 | 理由 |
|---|---|---|
| **P0** | Coding Agent 项目记忆 | 需求明确、用户集中、易于验证 |
| **P1** | IT/SRE/SOC 事故记忆 | 商业价值高、与现有 RAG 能力互补 |
| **长期** | 无人机救援 | 架构压力测试和示范，不是首要商业目标 |

Coding Agent 和 IT/SRE/SOC 是当前最接近生产化的商业场景，可以验证记忆合同、证据检索和跨会话记忆的核心能力。

无人机救援是长期架构压力测试场景，用于验证记忆系统在高频、高并发、强实时场景下的极限能力，但不是首要商业目标。
