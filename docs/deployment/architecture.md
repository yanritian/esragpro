## 三、核心模块说明

### 3.1 混合检索 (Hybrid Search)

**文件**: `backend/app/core/elasticsearch.py`

**算法**: RRF (Reciprocal Rank Fusion)

```python
def _rrf_merge(bm25_results, vector_results, k=60):
    """
    RRF_score(d) = sum(1 / (k + rank_i(d)))
    """
    scores = {}
    for rank, hit in enumerate(bm25_results, 1):
        doc_id = hit["_id"]
        scores[doc_id] = scores.get(doc_id, 0) + 1.0 / (k + rank)

    for rank, hit in enumerate(vector_results, 1):
        doc_id = hit["_id"]
        scores[doc_id] = scores.get(doc_id, 0) + 1.0 / (k + rank)

    return sorted(scores.items(), key=lambda x: x[1], reverse=True)
```
